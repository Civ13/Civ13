# Crossroads Mall: raid map and loot test range

Crossroads Mall is an original Civ13 firefight map set in a looted shopping
centre at a highway interchange. It takes the general idea of a mall raid
(parking lots, anchor stores, service corridors, keyed back rooms and timed
extraction points) without copying any other game's layout, store names or
assets. It reuses the existing EFT Factory mode: USEC and BEAR contractors
spawn at the parking entrances behind grace walls, Scavengers spawn inside the
mall, and standing in an extraction zone for ten seconds extracts the player
with the value of the items they carry.

The map also doubles as a test map for loot tables and a few mechanics. It is
never part of a vote rotation; like Factory it is selected by name
(`crossroads_mall`) through the launcher or the map swap script. It is not for
Gaia or any persistent server.

## Layout (160 x 150, one level)

| Area | Contents |
| --- | --- |
| South highway and east highway | Two carriageways with jersey-barrier medians, abandoned traffic, the interchange in the south-east corner and ramps into the parking lot. |
| Parking lot | Striped bays, nineteen car, van and truck wrecks, cart corrals, a security booth on the frontage and both PMC spawn pockets. |
| Northlight Electronics (west anchor) | Shelf aisles, a dead display wall, server corner and a sales counter. |
| Mall management suite and Security office | Keyed rooms above the west anchor. Management holds the safe and the stock cage key; Security holds rifle racks, ammunition and armour. |
| South store row | Willowbrook Pharmacy, Pagecount Books, Stride Footwear, Lumen Mobile, Threadline Apparel and Brightside Toys, each with a stockroom. |
| Concourse and The Crossing Food Hall | Lobby, kiosks that break sight lines, dining tables, Pepper and Pie, Kettle Corner and the management key. |
| Granary Market | Checkout lanes, shelf aisles with a cross aisle, bakery, cold storage, receiving and staff rooms, shutters onto the loading dock. |
| Ironbark Hardware and Garden (east anchor) | Tool aisles, a fenced garden centre, the keyed Ironbark stock cage and the dock office. |
| Loading yard | Fenced apron with truck wrecks, pallets, dumpsters and gates to the delivery and service sides. |

Extraction zones: Westbound shoulder (south-west highway), Northbound ramp
(north-east highway), Delivery gate (west of the loading yard) and Storm
culvert (west edge). Each has a sign. All four are reachable on foot from both
PMC pockets without any key.

Keys: the Security office key is in the parking security booth, the Management
suite key is on a food hall table, and the Ironbark stock cage key is inside the
management suite. Each key opens exactly one lock (both management doors share
one lock). Key doors can be lockpicked, kicked or breached with a pump shotgun
as usual; the range gate cannot.

## Loot test range

The fenced area along the north edge is indestructible and locked. Its gate key
(`/obj/item/weapon/key/modern/crossroads/range`) is never placed on the map;
admins spawn it or teleport in. Inside:

- Row A: one pad per `/obj/effect/spawner/lootdrop` table.
- Row B: one pad per `/obj/random` weapon, magazine, melee, armour and accessory table.
- Row C: explosives, bandages, drugs, the medical bag, barricades, trees and
  the two mine tables. Mine pads spawn armed mines; a warning sign marks them.
- Mechanics corner: a keyed test door with its key and a lockpick on a table,
  a pump shotgun and shells for breaching, an extraction test zone, a grace
  wall strip and a medical bench.

Each pad (`/obj/effect/crossroads_loot_pad`) rolls its table once when the map
loads and remembers what it spawned. Examining a pad shows its table, the number
of rolls and the last result. Two admin verbs in the Special tab work on any
map that has pads:

- Reroll Loot Pads: deletes each pad's previous roll and rolls again.
- Loot Pad Report: lists every pad with its table, roll count and contents.

`tests/crossroads_mall/test_crossroads_mall.py` projects the concrete loot
tables from `random.dm` and `loot.dm`, so adding a table without a pad fails
the offline suite. Add the new table to `PAD_TABLES` in the generator and
regenerate.

## Generation and checks

The DMM is generated by `tests/crossroads_mall/build.py`; do not hand-edit it.
Regenerate and test from the repository root with a verified interpreter:

```text
python3 -I -B tests/crossroads_mall/build.py
python3 -I -B tests/crossroads_mall/test_crossroads_mall.py
```

The offline suite checks the generator reproduces the checked-in file, the
dimensions, border and literal DMM values, that every type path exists in the
DM source, spawn and extraction placement, grace-wall containment, walking
routes from each spawn to each extraction, store and loot approaches, that the
keyed rooms and the range stay sealed without their keys, and one labelled pad
per loot table. The default `civ13.dme` build (Gaia) and a temporary
environment with the mall selected both compile with the pinned compiler.

Not verified offline: native movement, lighting, grace-wall release timing,
extraction value accounting and the actual random results of each table. Those
need a DreamDaemon run on the map.
