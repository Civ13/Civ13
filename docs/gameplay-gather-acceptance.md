## Prepare-only typed packet

from an exact clean frozen head. It hashes (never imports) the existing reviewed
Windows Job adapter and guard_config, and verifies the immutable containment

CPU/wall/memory/log/cleanup limits and residual native account/UDP traffic risk
are recorded in the manifest. It neither copies credentials/config nor launches
anything. Runtime folders contain only the public tracked native library.

```text
<python> -B scripts/gameplay_bridge/prepare_gather.py --expected-commit <FULL_SHA> --output <FRESH_EXTERNAL_FOLDER> --adapter-dir <REVIEWED_ADAPTER_FOLDER> --contained-repo <EXISTING_REFERENCE_CHECKOUT>
```

## Native source/cancellation profiles

Execute a new immutable packet only after source review and a new grant, binding its commit,
all source/asset hashes, BYOND516.1681, profile definitions and omission controls.
Keep compile-only profiles separate from native behavioral profiles. Source must
contain the real helper, canonical grass handler and survival callbacks; no
shortened delay, stock lock repair or alternate output producer is permitted.

Compare stock, disabled and enabled-with-null-context runs on identical synthetic
inputs. Record wait result, elapsed ticks, may_do_after, started/finished callback
counts, survival_actions and survival_rest_since, grass busy flag, exact turf
identity/type, flint identity/location and cutting identities/amounts. Include
ordinary success, movement/hand/incapacity cancellation, zero delay, TRUE-first
overlap rejection and FALSE-first overlap/early-unlock behavior. The last is an
existing stock behavior, not a lease defect to fix in this slice.

Enabled explicit gather must use the original worker-owned lease end to end.
Record denial before callbacks for nonlease, wrong owner/body/target/kind/request,
stale generation, cancelled/deadline-expired/current-pointer mismatch, replay and
nested use. Check entry, first wake, later wake, final and zero-delay revocation;
cancelled work must release busy/ordinary lock/callback state and produce no late
cuttings or turf replacement after the normal30tick completion horizon. Replacing
the service lease must never rescue the captured old lease or claim the new one.
Successful gather must pay the real duration and create exactly two cuttings via
the canonical handler, with no duplicate effect on same-ID retry.

Use an ordinary FALSE-first same-actor wait overlapping a bridge gather, then
cancel only the gather. The ordinary wait must retain its own stock result and
callbacks; it must never capture a bridge context. Also test a different actor,
unrelated target, null ordinary wait and nested replay of the same lease. The
one-use flag is never reset, including failed/finished invocations.

Mutation profiles must independently omit type/claim/wake/final/grass-postwait
guards, omit a forwarding hop, reintroduce ambient lookup, or reacquire the new
service lease after yield. Each must fail a named expected assertion; unrelated
runtime/compiler diagnostics, timeout or generic failure cannot count as a
successful negative control. Callback-order mutation must detect a leaked start.
Operator JSON context injection must be rejected by the actual fixed-key catalog.

An isolated no-client helper fixture may declare an identity boundary seam to
exercise waits; it must report that seam and cannot establish ordinary player
authority, visibility or connected-client behavior. It cannot replace the next
layer. No historical packet/result is reusable as native proof of these changes.

## Ordinary joined non-admin consent/bootstrap slice

1. Core prepares a separately authorized isolated enabled build and normal
   startup with autosave policy explicitly bound. No imports/hidden setup state
   may be confused with an already observed client baseline. Record the actual
   commit/build/runtime identity, map and normal ready state before actions.
2. A real ordinary non-admin player joins through the existing native admission
   path. Verify living human/current own client, no holder/admin rights, normal
   vision/eye and natural Life service. Backend Join remains unsupported; this
   step cannot count as physical Join/menu proof without actual UI evidence.
3. That player explicitly toggles existing gameplay consent on its own client.
   Observe consent bound to that exact current body. The existing R_ADMIN
   operator assigns only that consenting player and a narrow capability set;
   operator assignment is a separate authority plane, never a player action.
   No possession, spawn, credentials, public endpoint or new diagnostic API.
4. Use the existing versioned mailbox with a deterministic inert driver, no
   model. Read bounded discovery/observation; verify current visible grass and
   held sharpened-flint IDs. Walk/pickup/swap/examine use normal adapters as
   needed. Supplied public fixture resources must be declared, never claimed as
   naturally obtained survival resources. Cap at24 submissions and120seconds.
5. Submit gather once, retain its request/action/observation IDs, poll that exact
   receipt, and verify normal duration, canonical output/turf changes and public
   observation reset/removal. Repeating the identical ID must have no second
   effect; altered payload/stale epoch/hidden or peer inventory ID must deny.
6. In a separate independent gather, request cancellation/STOP and verify actual
   worker quiescence and absence of late effects. Acknowledged cancel/unknown
   transport status is not completion. Confirm unrelated ordinary player wait
   isolation, then consent off/body replacement/disconnect revoke ownership and
   require fresh consent/assignment/epoch. No automatic worker retry or rollback.

Screenshots, if separately captured by the UI owner, must identify the exact
session/time and observed action. Source logs/backend receipts never claim to
capture pixels. Private refs/identities remain private; any public report is an
explicit allowlist summary. Fixed output/rate/deadline/audit bounds remain active.

Acceptance stops at this joined-player gather vertical slice. Agent Join, timed
water/craft, containers, broad equipment, repair/rest/combat/death/respawn,
vehicles/shuttle/party/extraction and whole-game survival remain unsupported or
unverified. Add subsequent adapters only with explicit context forwarding and
their own authoritative costs/range/LOS/permission/cooldown/completion evidence.
