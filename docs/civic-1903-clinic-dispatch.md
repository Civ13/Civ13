# 1903 clinic dispatch pilot

Use paper and wired telegraphs to arrange clinic deliveries without Discord,
admin involvement, or a new job board. The supplies still travel physically.
The telegram confirms **dispatch**, not delivery, and cannot award payment
or ownership.

1. At the requesting town, name its telegraph with the existing **Name**
   command. Connect both stations to the same utility pole network. Keep a
   teleprinter with readable room on a sheet next to the requesting telegraph
   if you want a paper record.
2. Write a clinic notice on ordinary paper using the existing pen/editor.
   Include a unique local reference (1-12 letters/digits, e.g. **CLINIC07**),
   requested quantities, the delivery point, the receiving telegraph's
   exact name, and who issued the notice. Sign/date it using the usual
   paperwork controls. Copy the notice at a printing press before posting
   it; insert it as **Original**, insert blank paper as **Copy** (choose
   **Document copy** if asked), then use the press to make the copy. Post a copy on a mounted noticeboard and carry the others.
   Ordinary paperwork custody, reading languages and copying rules apply.
3. Once the supplying town has actually sent the goods, stand next to its
   telegraph and choose **Confirm Clinic Shipment**. Enter the receiving
   station name and the notice reference. Only the one matching wired
   station receives the acknowledgement; if names collide or the line
   cannot reach the station, nothing is sent. A confirmation says whether
   it was also printed. The origin station name is a player-set label,
   not proof of a sender's identity.

The original one-word broadcast and nomad request route is unchanged.
There is no offline queue, delivery retry, cross-region route, or global
station registry. This uses the existing Electricity requirement for
crafting telegraphs and teleprinters, not a new date or tech gate.
