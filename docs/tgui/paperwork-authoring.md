# Disabled language-aware authoring session

This slice supplies an internal server-owned append session. No player Topic,
TGUI component, verb or action constructs it. Authoring and study remain disabled.
It depends on the merged canonical copying/transaction service; it does not
change legacy paper editors, subtype overrides or container access.

Paper constructor readiness is a runtime-only flag set after its existing delayed
capacity callback. A pending constructor refuses editor admission, preventing a
first classification from suppressing an unpaid legacy capacity debit. No
existing capacity calculation or legacy editor route changes. Native callback
ordering remains unverified.

A future caller binds an actual plain paper, controller/client and active held
pen, then calls begin(). Opening, snapshotting, cancelling and rejected first
writes never initialize a classified record. The first accepted append creates
revision 1 and its first section together, with one capacity debit. Later appends
use the existing prepare/commit transaction. Bodies, titles and signatures are
plain text; form-field authoring and formatting are later slices.

Each action checks the exact client/body, current actor state, actual bound pen,
physical admission, custody context, canonical reference and canonical/legacy
fingerprints. A successful write rotates an opaque lease. Stale packets cannot
rebase, replay, close a newer session or silently overwrite another writer.
A pen signature comes from the actual pen getter, retaining deliberate forgery,
ink and crayon behavior. The getter is followed by fresh authority checks.
Cancel may close an authenticated stale view after access is lost; retire()
drops runtime references without clearing unrelated using_object state.
The future UI owner must invoke retire() on close/logout/transfer; this slice
does not install lifecycle hooks or detect a custody excursion between requests.

Writing choices use existing spoken-language membership and stable written IDs,
with no mute restriction, universal/dead/admin grant, language XP or translation.
The current eligible default is only a preselection. Each append revalidates the
chosen language. Existing sections retain their own language IDs and originals.
snapshot() returns only current eligible choices, revision/lease/capacity and the
shared per-viewer projection. Every tagged text kind is redacted server-side
when unknown; canonical records, fingerprints and unknown originals are absent.
Inherited eager initialize/canonical_copy/project entry points are disabled on
the editor context. Legacy content remains explicitly legacy_unclassified with
existing readability and bytes; it is never interpreted as Markdown or assigned
invented language provenance. Ink visibility and the existing reader literacy
restriction remain separate from language knowledge.

This bounded slice admits held paper, adjacent turf paper and paper in held
clipboards/folders. It pins the selected custody context. Bundles, envelopes,
noticeboards and paper subtypes are refused by this new session; their existing
player behavior is unchanged. Broader authoring adapters require separate review.
No stored bytes, languages, signatures or fields are rewritten merely by opening.

Validation is offline projection of complete production procedure bodies using
the existing explicit inert engine/client/list seams, plus causal guard-omission
controls. It is not native Unicode indexing, pen callback ordering, save/load,
real client admission, close/transfer acceptance or in-game TGUI evidence.
The runtime session and its references are explicitly excluded from persistence.
No new dependency, native fixture admission or runtime test is selected by CI;
the existing paper_documents offline family is extended. Production compilation
and hosted CI remain pending publication/review; no live migration is included.
