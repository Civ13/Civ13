# tgui migration notes (historical)

These are the working notes written while Civ13's windows moved from NanoUI
templates to tgui, one note per screen or paperwork step. They are kept as a
record of why each screen behaves as it does.

They describe the migration as it stood when each note was written. In
particular, the classic NanoUI fallback, the **Classic interface** button and
the server startup watchdog they mention were retired in #5628; BYOND 516 is
the minimum client and there is one renderer.

For current behavior read [the tgui guide](../README.md) and
[tgui/README.md](../../../tgui/README.md).
