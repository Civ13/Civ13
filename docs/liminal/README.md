# Liminal Facility design milestone

Read [mode loop and decisions](MODE-DESIGN.md), [authored room contracts](ROOM-GENERATION.md)
and [source, export and acceptance plan](SOURCE-AND-ACCEPTANCE.md).
The [early-1990s and shared-level policy](ERA-AND-SCENARIOS.md) separates the
escape scenario from the independently designed powered-gateway expedition.
The original [room catalog](room-archetypes-v1.json) and
[bounded example config](liminal-example-config.json) freeze the small topology
proof's design inputs. They contain no copied art or native mode registration.

This design precedes implementation commits. It chooses a finite offline-generated
map, existing Civ13 assets first, explicit authored progression and independently
validated room/door/clearance topology. It does not approve third-party asset
ports, native execution, live server selection, merge or deployment.

Design audit baseline: Civ13 commit
`10d264e5896221b34949ee4b67c0fd2b94bde249`. Existing surface/oceanic/cavern
profiles retain their own versions and evidence. The indoor backend must remain
separate from the Nomads terrain palette and its native mapping.
