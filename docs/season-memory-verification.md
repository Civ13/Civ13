# Season memory verification

PR #3021 fixes duplicate grass registry entries, obsolete dirt soil-recovery chains, and repeated area-list allocation in Fall. The production-body fixture passed 20 cycles over 2,500 tiles; an earlier 350,000-tile synthetic probe passed two cycles. Synthetic memory does not establish production OOM remediation or long-runtime stability.

Actual isolated gameplay at a7e2ce748b07a178a2b79059829b89bd038fa457 used BYOND 516.1681, Nomads Temperate 155x225x2. One Spring/Summer/Fall/Winter/Spring cycle completed, with grass restored after the normal 300-second thaw. The naked actor suffered cold injuries; limited Winter movement and Spring tree Examine worked, but post-thaw free movement was not established. Videos are genuine sampled captures encoded at 2 fps, not timing benchmarks.

[Direct season attachments and sampled frames](https://github.com/Civ13/Civ13/pull/3026#issuecomment-6106348906) replace repository-hosted generated media. Spring, Winter, thaw and video attachments were rechecked with HTTP GET 200 before removal. The older nine-file bundle remains recoverable in published commit a7e2ce748b07a178a2b79059829b89bd038fa457 under docs/evidence/season-memory; all nine Git blob hashes were verified. Its images document an ancestor run at 339675da2d3120743a4b8816784801ae30179390, with BYOND server 516.1681/client 516.1669 and admin rejuvenation after cold injury. They do not verify a later commit. Published history was not rewritten.

Reproduce with tests/memory/start-gameplay-evidence.ps1 -ByondBin <516.1681-bin> -Scenario season. The launcher requires a clean committed checkout and authenticates readiness before publishing session.json. Connect through the printed localhost port. Use query-gameplay-evidence.ps1 with SessionJson and ByondBin for prepare, join once playing, then run four times. Wait at least 300 seconds after Spring and Examine a nearby tree. Stop only task-owned PIDs afterward. The adapter is excluded from production civ13.dme; these steps do not authorize production operations.

Harness regressions: tests/memory/test-gameplay-evidence.ps1 covers empty/non-JSON/wrong-commit/failed responses, failed native Git status, bounded readiness retry/exit/timeout and safe cleanup after copy failure. Real BYOND startup, no-client run rejection and unreachable-server rejection were verified separately. The harness-only follow-up did not repeat graphical acceptance; the original screenshot waiver applies.
