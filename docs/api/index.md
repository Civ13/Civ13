# Civ13 source API reference

This reference is for DM contributors, distinct from the player wiki and official website.
It is generated from `civ13.dme` by SpacemanDMM dmdoc. Documentation coverage is incremental;
undocumented declarations and inactive preprocessor branches are not a complete API contract.

Start with [/datum/callback] and its [/datum/callback/dynamic] subtype for synchronous
and asynchronous proc invocation. Browse the module and type trees for existing subsystem documentation.
