# Shared physical-interaction guard

`python3 scripts/ci_baseline.py unit --suite physical_interaction --output /tmp/touch-check.json` executes
production guard control flow offline using the existing fail-closed DM adapter.
Adjacency and chat are fake engine boundaries. Coverage includes null/distant
users, restraints/buckling and exact feedback order, each incapacitation flag,
valid actors, both forwarding wrappers, and a removed-lying-gate negative control.

This does not establish native `Adjacent()` semantics, client interaction,
stationary-gun use or save/load acceptance. The abstraction deliberately retains
the existing guard, including its posture restrictions and feedback order;
caller-specific policies and overrides remain in `can_touch`.
