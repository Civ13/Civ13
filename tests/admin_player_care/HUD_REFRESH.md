# HUD membership and appearance recovery

Run the bounded offline suite with an explicit verified Python executable:

```powershell
& $PythonPath scripts/ci_baseline.py unit --suite admin_player_care --output $EvidenceJson
```

`test_hud_refresh.py` projects the production show/destroy/check/update HUD
procedures and appearance wrapper with inert screen lists, plane constructors,
deletion, input and body-appearance effects. It checks unrelated screen and
processing ownership, idempotent reattachment, missing collection/renderer
recovery, scope reapplication, style cancellation and a real style transition.
Mutation controls reintroduce global clears, raw-plane backdrops, broad processing
clears and omitted recovery/style guards. Species scheduling and cosmetic/healing
call sites use explicit source contracts. No test launches a compiler, daemon,
browser, network service or native fixture. The bounded CI registry names both
test files explicitly; the older native item-Clean fixture remains separate.

Human collection replacement removes only its registered controls from screen
and HUDprocess. Renderer, vehicle, wizard, map, open-storage and other transient
owners remain attached. show_HUD repairs missing owned/auxiliary members without
rerunning plane backdrops. Constructors and regular sight updates still initialize
the renderer and update light-mask bypass policy. Actual login/teardown retains
the ownership reset, and explicit Regenerate Icons retains its default HUD check.

Appearance-only callers use regenerate_appearance: all ordinary body/equipment
regeneration is kept, with HUD recovery only for an absent datum or missing
inventory/need collections. Item Clean retains its existing FALSE argument.
Missing-state recovery uses the default regeneration ordering, so HUD inventory
positions exist before equipment icons are published; it is not a late repair
after appearance-only regeneration.
Real species changes discard the human collections once and let the existing
deferred default regeneration rebuild them; the same body's plane datum remains.
Cancel/unchanged ChangeHUD choices return before preference writes/regeneration.
