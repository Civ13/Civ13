# Seasonal construction checks

Run the offline tests with a verified Python interpreter:

```powershell
& $PythonPath -B -m unittest discover -s tests/seasonal_construction -v
```

Production bodies are projected with an explicit instruction dictionary; new
syntax fails preparation. Native lists, deletion, locations and health are Python
adapters. Save trace tests carry health/debt across a simulated restart; the native
codec is not executed. Source checks cover constructors, both historical cover
lifecycle definitions, Del/Destroy cleanup, roof partial-save fields and inherited
runtime exclusions. See [policy/rates/limits](../../docs/seasonal-construction.md).

Prepare the unrun native fixture, optionally with `--control mode`, `replay`,
`save-debt`, `paired` or `contents` (reinstates the superseded terminal deferral):

```powershell
& $PythonPath -B tests/seasonal_construction/prepare.py --output <empty-temporary-directory>
```

This only writes a DME, adapted startup sources, probe, patch and hash receipt.
There is no compiler, daemon, client, native runner or resource reservation.
The probe is uncompiled and may require repairs after the native hold is cleared.
Do not treat its JSON schema or source preparation as a passing test receipt.

The prepared fixture covers native construction rates and qdel, exact exclusions,
paired-slab removal from the registry, mode/forced/repeated transition counters,
occupied terminal damage/destruction dispatch, and real disk entry save/load with paid debt and
historical runtime fields. It does not yet cover full season queue/terrain work,
fresh-process world recovery, representative populations or connected clients.
Those remain explicit parent-review acceptance work. The fixture's direct
transition helper is an adapted boundary; it does not claim full-game seasons.

`construction_contract.py` permits only the exact observer addition in legacy
debris-file parity tests. It verifies the original clock body and one unconditional
construction call before removing that call for comparison; omission/duplication,
movement and changed-debris controls reject. Historical revisions stay fixed.
The 2026-10-26 master reconciliation does not run or rewrite the original native
packet. Current ordinary compilation targets 516.1688; a native adapter and
separate admission review are still required before running the prepared fixture.
