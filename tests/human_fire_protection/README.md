# Burning human heat-protection projection

`py -3 -B -m unittest discover -s tests/human_fire_protection -v` projects the
complete post-emote body of the production `handle_fire` procedure and a frozen
pre-change body through the existing restricted source adapter. The harness
models clothing flags, weighted thermal protection, organ iteration, damage,
and deterministic probability results. It compares body temperature, damage,
RNG-call order and other events, accounting only for the eliminated second
flags calculation. It exercises temperature and species thresholds, uncovered,
partial, full and overlapping coverage, and checks that a wrong-flags mutant
is detected. The fake thermal weights and rounding are intentionally simplified;
they are shared between the compared versions and are not an engine oracle.

This is offline source-derived evidence. It does not execute DM, test native
BYOND dispatch or RNG, validate engine floating-point and list behavior, establish
player-visible results, or measure opcode counts or runtime speed. The modeled
helper has no mutation or yield between the two original scans; this test cannot
prove that property for arbitrary future overrides.
