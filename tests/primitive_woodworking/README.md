# Offline manual woodworking checks

Run `python -I -S -B -m unittest discover -s tests/primitive_woodworking -p 'test_*.py' -v`
with a real interpreter (on this Windows host use its explicit Python 3.13 path).
The same command is wired to the hosted evidence-checker job with `python3`.

The fail-closed adapter executes production admission, constructor snapshots,
commit, ownership release and wait wiring. Types, item operations, callbacks and
waiting are injected. It is not native DM, engine collision, initialized-world,
real stack merging or savefile evidence.

The initial cancellation matrix reported an actor-move failure because two fake
turf records compared structurally equal. Fixture turfs now carry distinct
identity tokens, matching DM reference identity. No production move guard was
weakened. Retain this failure as projection-development evidence, not gameplay.

The first broader Atlas check also rejected missing audit provenance on the new
acquisition rows. Rows now carry a source digest and the last matching committed
source revision (or explicitly `uncommitted` before a checkpoint); the assertion
was retained. The final generated catalog must bind the committed source.
The new end-to-end Help check then exposed raw item acquisition keys that did not
match the Atlas's canonical material keys, hiding the flattening route from Help.
The exporter now canonicalizes the route keys and variants. Both the existing
Atlas resource-membership assertion and the new Help assertion remain in place.
An optional image-metadata probe could not import Pillow on this host. The focused
suite therefore checks the genuine reused PNG/DMI state metadata with standard
library chunk parsing and zlib; no dependency installation or generated art is used.

The current product contract includes separate small wood pieces and crude planks,
and zero-tool-wear flattening by sharpened flint or a sharp non-wood working material.
Whittling remains the separately specified flint-or-harder-knife operation.
Earlier direct finished-plank draft output was
superseded by the user's explicit crude-plank instruction before this checkpoint.
