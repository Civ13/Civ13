# Computers

A **minicomputer** is a cabinet computer from the 1960s. On its own it is an empty case: the parts you fit inside decide what it can do. With a processor and a tape drive it runs **Unga OS**, a command-line system with a **Files** program for writing, reading, printing and copying text files.

## Getting one

- Research **Electronic Computing** on your faction's [tech tree](Guide_to_Research.md). It needs Automation and Electricity, and Digital Computing now comes after it.
- Craft the parts from electronics in the electronics section of the crafting menu. Electronic circuits are made from copper; see [Crafting](Guide_to_Crafting.md).

| Part | Electronics | What it does |
| --- | --- | --- |
| Minicomputer | 8 | The case. One processor, one storage, one diskette drive and two expansion slots. |
| Transistor logic board | 3 | Processor. Needed to start the computer. |
| Tape drive | 2 | Storage, 16 KB. Needed for Files. |
| Diskette drive | 2 | Reads and writes data diskettes. |
| Data diskette | 1 | Removable storage, 4 KB. |
| Line printer | 4 | Prints files on paper (expansion slot). |

Later research brings faster parts that fit the same case: the **microprocessor** and **hard drive** (64 KB) with Digital Computing, and the **multicore processor** and **solid-state drive** (256 KB) with Consumer Electronics.

## Setting it up

1. Place the minicomputer. Use a wrench to fasten or unfasten it.
2. Open the case with a screwdriver, then use each part on the computer to fit it. A full slot refuses another part. Close the case with the screwdriver again.
3. Drag a powered electrical cable onto the computer. It draws 3 power while it is on; see [Power & Batteries](Guide_to_Power.md).
4. Click the computer to start it. If something is missing, it tells you what, such as "It has no processor."

The window opens on the command line. Click a command or type one: `RUN FILES`, `HARDWARE`, `HELP`, `HOME` or `OFF`.

## Files

- **New file** opens an empty editor. Type, give the file a name and press **Save**. Names are up to 24 characters and must be unique on the drive. A file holds up to 2,500 characters.
- **Open**, edit and save a file to change it, or **Delete** it.
- Each KB of storage holds 1,000 characters of names and text. A drive that is full refuses new files.
- **Print** a file onto a sheet of paper. Load the printer first by using blank paper sheets on the computer (up to 20).
- **Diskettes:** use a data diskette on the computer to put it in the diskette drive. Copy files to it or from it, then **Eject** it to carry the files to another computer.

## Parts and theft

Parts are ordinary items. With the case open, the **Hardware** tab can remove any part, and pulling the processor or drive out shuts the computer down. Files live on the drive or diskette itself, so whoever takes the drive takes the files. Computers, their parts, files, diskettes and loaded paper are kept across server saves.
