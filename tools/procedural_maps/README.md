# Offline procedural maps

Generate new typed geography, a static Civ13 `.dmm`, its required semantic
sidecar and an original data preview. This Python tool never launches BYOND,
opens a native save or replaces a live map.

Start with the [beginner guide and configuration reference](../../docs/procedural-maps.md).
From the repository root, with Python 3.11+:

```sh
python3 -m tools.procedural_maps preset --out data/procedural_maps/config.json
python3 -m tools.procedural_maps generate --config data/procedural_maps/config.json --out data/procedural_maps/demo
python3 -m tools.procedural_maps verify data/procedural_maps/demo
```

Windows: use your verified Python executable in place of `python3`; the guide
shows PowerShell commands. No pip dependencies or engine installation are
required for generation/validation.

SURFACE generation is implemented, with N/S/E/W edge spans, one confluence and a
through-lake. OCEANIC schema 3 generates separated islands, enclosed fresh lakes,
connected deep sea and ship-clear routes. Use `preset --profile OCEANIC` for its
versioned configuration. Cavern generation and legacy oceanic schema 1 reject
explicitly. Native resource, hydraulic,
climate/elevation and persistence integration remain incomplete. FOOD/WOOD/STONE
are abstract sidecar labels, not playable supplies. No reference-matching seed
has been demonstrated. A static parse-back check is not native gameplay or
Dream Maker editor acceptance.

Tests, including original v0.1/v0.2 golden maps and all prior offline contracts:

```sh
python3 -I -B tests/procedural_maps/run.py
```

The original source is covered by the repository's [license](../../LICENSE).
No DFLib code/binary, reference screenshot, copied game source, third-party art,
private runtime research or large raw IR output is included. The small preview
is generated by this tool's own renderer. Catalog source pins and the frozen
resource **proposal** are under `catalog/`.
