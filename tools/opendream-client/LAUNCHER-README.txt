Civ13 launcher for Windows x64

1. Extract this ZIP to a folder.
2. Double-click Civ13.cmd. Keep all four script/config files together.
3. Allow the download to finish (approximately 761 MB for the initial client).
4. Choose 1 and sign in with your own Space Station 14 account.
5. Choose 2 for Nomads or 3 for TDM.

Run Civ13.cmd again next time. It checks the Civ13 repository update channel
and installs checksum-verified releases automatically, without Administrator access.
If the check is unavailable, it uses the last successfully installed version.
Your account settings are kept by the existing launcher, outside the version folders.
Keep old versions while a game is running. This launcher does not delete them.

The initial published channel currently points to the original public client.
The movement fix will arrive after its candidate release is accepted and published.
The update channel needs to be merged into master before remote update checks work;
until then the bundled verified release works. This is an experimental client.
