Civ13 legacy OpenDream launcher for Windows x64

This ZIP, Civ13.cmd, Launcher.ps1, Sign-In.cmd, Play-Nomads.cmd,
Play-TDM.cmd and their existing shortcuts launch experimental OpenDream.
They are not the native BYOND player entrypoint.
For native BYOND servers use the accepted single-file Civ13.exe release,
then choose ValZarGaming and Nomads or TDM. Sign into BYOND Pager with
your own account. Server availability and release acceptance are separate.

Extract this ZIP and double-click Civ13.cmd. Keep all six files together.
The launcher automatically checks for both launcher and client updates.
For experimental OpenDream, choose Sign in first, then Nomads or TDM.
Use your own account.
No Administrator access is needed. Downloads are checksum verified.
Existing account settings and older client versions are preserved.
If the launcher update check fails, the bundled launcher continues.
Client update checks fall back to the last installed or bundled channel.

Users of the original launcher must download this small replacement once
because the original launcher only knew how to update the client.
The client is experimental; held-key graphical acceptance remains unverified.
